# 🌍 AI-Powered Language Translator Chatbot

Welcome to **Translate** – an AI-powered chatbot designed to help tourists overcome language barriers and communicate seamlessly while traveling the world.

## ✨ Features

- 🔁 **Real-Time Language Translation**  
  Translate text instantly between multiple languages using AI.

- 💬 **Interactive Chatbot Interface**  
  Communicate naturally with a friendly chatbot that understands your inputs.

- 🌐 **Tourist-Friendly**  
  Designed specifically for tourists to get quick help with basic conversation.

- 🎯 **Simple & Clean UI**  
  Easy to use, no tech knowledge required – just type and translate!

- 🧠 **AI-Powered**  
  Uses AI to provide smarter and more contextual translations.
